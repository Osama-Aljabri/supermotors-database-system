# 🚗 SuperMotors Database System

## 📌 Overview
This project presents a complete relational database design for SuperMotors, a car dealership that sells vehicles and provides maintenance and repair services.

---

## 🎯 Objectives
- Store and manage customer, vehicle, sales, service, invoice, parts, and employee data
- Track vehicle sales and after-sales services
- Support multi-salesperson commission handling
- Generate business reports for sales, payroll, inventory, and service history

---

## 🧱 Main Components
- Conceptual Model (ER Diagram)
- Relational Schema
- SQL DDL Implementation
- Sample Data
- Business Queries
- Reports and Stored Calculations
- Security, Backup, and Maintenance Recommendations

---

## 🗂️ Entities Included
- Customer
- Car
- Salesperson
- Mechanic
- SaleTransaction
- SaleLine
- ServiceTicket
- ServiceAssignment
- Part
- ServicePart
